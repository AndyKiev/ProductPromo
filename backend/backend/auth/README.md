# auth — DEV stub

`jwt_auth.py` here is a development stand-in so the app boots and the SPA can
log in without a real IdP. To make it production-real, port from the talent
project:

- LDAP bind / user lookup (`ldap3`) → resolve the employee + language.
- RS256 JWT issue/verify using `auth/keys/jwt-private.pem` / `jwt-public.pem`
  (generated by `generate_keys.sh`).
- Implement `get_current_active_auth_user` to decode the bearer token, load the
  employee, and return the full `EmployeeSchema` (including the real language so
  the i18n name resolution picks ukr/eng correctly).
